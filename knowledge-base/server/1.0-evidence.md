# Valheim 1.0 evidence

Receipts for the [1.0 migration](../../docs/server/1.0-migration.html). One row per claim. Status
is what the sources actually support, not what we expect. Quotes are verbatim.
Every row carries the date it was checked. Update a row when its status changes.
Keep unique collected research; consolidate or delete only material superseded
by stronger evidence or duplicated elsewhere in this file.

Status meanings:

- **Confirmed**: a primary source states it.
- **Observed**: read directly off our server.
- **Reported**: player or third-party reports only, no primary source.
- **Unconfirmed**: searched, nothing found either way.
- **Expectation**: our inference, no source.
