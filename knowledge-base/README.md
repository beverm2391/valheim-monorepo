# Knowledge base

This directory is the repository's home for durable research, external source
shelves, implementation references, and conceptual notes. The pages keep their
source-specific shape and voice. Product contracts, live ideas, development
instructions, migration records, and operational runbooks stay with their
existing owners.

- [Research notes](game-design/NOTES.md) for source-specific ideas, quotes, and
